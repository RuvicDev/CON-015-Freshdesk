1. ¿Qué es y para qué sirve?

Freshdesk es una plataforma de soporte para gestionar tickets de clientes. El conector permite crear tickets, actualizarlos, agregar notas y consultarlos por ID.

ticket.create_ticketCrea un ticket.
ticket.update_ticketActualiza un ticket.
ticket.add_noteAgrega una nota.
ticket.get_ticketConsulta ticket por ID.

2. Prerrequisitos

  • Cuenta o trial Freshdesk.
  • Dominio Freshdesk.
  • API Key de un agente con permisos.

3. Configuración en Freshdesk

  1. Entra a Freshdesk.
  2. Abre tu perfil de usuario.
  3. Copia la API Key.

4. Permisos requeridos

El agente debe poder crear, actualizar, consultar tickets y agregar notas.

PermisoPara qué sirve
Crear ticketsAbrir tickets nuevos
Consultar ticketsObtener un ticket por ID
Actualizar ticketsCambiar campos de un ticket
Agregar notasRegistrar notas en un ticket

5. Configuración en Ruvic

Completa dominio Freshdesk y API Key. La API Key se guarda como secreto.

6. Verificación

Ejecuta Probar conexión y crea un ticket de prueba en un portal trial.

7. Solución de problemas

401/403API Key, dominio o permisos inválidos.
404Ticket no encontrado.
429Rate limit de Freshdesk.

8. FAQ y seguridad

No compartas API Keys. Usa un portal de prueba para validar y confirma antes de crear tickets reales.
